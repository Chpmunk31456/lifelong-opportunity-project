## Publication claims and limitations

This release baseline verifies repository availability, package completeness, document-safety checks described by the project tooling, and the specific QA evidence recorded in the repository.

It does **not** claim that every translation has received independent human linguistic certification, that every guide has received independent professional review, that every PDF is formally accessibility-certified, or that legal, financial, medical, licensing, immigration, tax, or other regulated guidance has been independently certified. Machine-assisted translation and project QA status must continue to be represented accurately in guide-level records.

## Separate controlled revision program

Draft PR #17 contains a controlled 2026 content-refresh program that is sequentially revalidating and expanding Guides 00–100 under a stricter opportunity standard. That work is intentionally separate from this complete-collection availability release baseline.

A guide revised through that program should replace its prior edition only after the guide-specific publication gates pass. Until then, the existing published edition remains the repository edition of record.

## Ongoing maintenance

The complete collection remains subject to periodic factual, link, accessibility, translation, and technical review. Material changes to wages, occupational outlook, licensing, accreditation, apprenticeships, education benefits, worker protections, technology, accessibility requirements, or official resource links should trigger an earlier review.
